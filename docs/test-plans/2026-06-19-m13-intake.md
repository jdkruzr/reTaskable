# M13 hardware test plan — note-anchor intake (reTaskable receiving end)

M13 builds the reTaskable side of "lasso → to-do": an **intake spool** the backend
drains, an **anchored create** (X-property note anchor on the VTODO), and an **anchor
line** in the ListView. The xochitl-side capture hook is M14, so we verify here by
**simulating the hand-off** with a hand-dropped JSON file.

Automated coverage: 120 backend tests pass (`cargo test --bin retaskable-backend`,
110 → 120). The on-device checks below are the parts unit tests can't reach.

## Setup

1. Build + install: `cd app && ./build-rmpp.sh && ./install-device.sh`.
2. Device must have a **synced** calendar configured (open the app, tap Sync once).
   The drain attaches creates to that calendar; an unsynced/unset one is a no-op.

## Cases

### 1. Happy path — anchored to-do appears, spool cleared
```
ssh root@10.11.99.1 'mkdir -p /home/root/.local/share/retaskable/intake'
scp -O docs/test-plans/m13-sample-intake.json \
    root@10.11.99.1:/home/root/.local/share/retaskable/intake/email-bob.json
```
Open reTaskable. **Expect:** a new open to-do "Email Bob the Q3 numbers" with a second
line `📓 Q3 Planning · p.3`. The spool file is gone:
`ssh root@10.11.99.1 'ls /home/root/.local/share/retaskable/intake/'` → empty.

### 2. Anchor survives the CalDAV round-trip
Tap **Sync**. On the server (Nextcloud web → the task's `.ics`, or the UltraBridge
store), confirm the VTODO carries:
```
X-RETASKABLE-SOURCE-DOC:e0cef3e0-4e69-471b-a3ca-7e00d1a72e79
X-RETASKABLE-SOURCE-PAGE:p:0.500000
X-RETASKABLE-SOURCE-LABEL:Q3 Planning · p.3
```
Pull the device DB and confirm `ical_text` carries them too:
`scp -O root@10.11.99.1:/home/root/.local/share/retaskable/db.sqlite /tmp/` then Python
`sqlite3`. The `📓` line should still render after the sync (read back from cache).

### 3. Graceful degradation — no anchor
Drop a file with only `{"summary":"Pick up dry cleaning"}`. **Expect:** a plain to-do,
no `📓` line, no error.

### 4. Malformed-file safety
Drop `{ not valid json` as `junk.json`. **Expect:** app still opens, list renders, the
junk file is **left in place** (not deleted), and the log notes a skip:
`ssh root@10.11.99.1 'journalctl -u xochitl -f' | grep retaskable` → `intake skip malformed`.

### 5. Drain-on-sync
With the app already open, drop a new intake file, then tap **Sync** (don't relaunch).
**Expect:** the new to-do appears after the sync (sync drains the spool too).

## Notes
- The drain runs on app launch (MSG 18) and at the top of every Sync.
- A failed unlink after a successful enqueue logs `may double-create` — shouldn't happen
  in practice (same process just read the file).
